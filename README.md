# Paradise Nursery Shopping Application

Paradise Nursery is a responsive online plant shop built with React and Redux Toolkit. Browse curated houseplants, filter by category, add plants to a cart, adjust quantities, and review your order.

## Features
- Landing page with nursery mission and call to action
- Air Purifying, Aromatic, and Low Light plant collections
- Redux Toolkit cart state with add, remove, and quantity controls
- Dynamic cart item count, subtotals, and order total
- Responsive desktop and mobile layout

## Setup
```bash
npm install
npm start
```
