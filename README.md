# Git and GitHub Practice Project

This repository is a simple Git/GitHub practice project created for learning version control, repository setup, collaboration, and basic scripting.

## Project Overview

This project is designed for beginners who are learning the fundamentals of Git and GitHub. It includes a small Bash script that calculates simple interest using the standard formula:

Simple Interest = Principal × Rate × Time / 100

## Contents

- A beginner-friendly Bash script for simple interest calculations
- Project documentation for setup and contribution guidance
- Standard community files such as a license and code of conduct

## Basic Information

- Project type: Practice repository
- Primary language: Bash
- Purpose: Git/GitHub learning and skill development
